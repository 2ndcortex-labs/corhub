# Root beacon

This folder is the root of a corhub installation. Claude Code sessions here are launched only from `corhub/nexus/`.

If the current working directory of this session is anything other than `<this folder>/corhub/nexus/`: stop. Report that the session was launched from the wrong folder, and give this command to relaunch:

    cd <this folder>/corhub/nexus && claude or cd <this folder>/corhub/nexus && claude --resume

Take no other action.
